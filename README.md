# 🚗 汽车成本工具箱

面向汽车行业的**成本工具与知识库**：成本估算、材料价格查询、成本方法论。

全部计算在浏览器内完成，**不依赖任何外部 CDN、不上传任何数据**，可在离线环境与企业内网使用。

> 在线使用：**https://gds-cb.github.io/cost-model/**

---

## 📚 内容页

### 🔩 材料价格库 `materials/` （免费）

按**汽车行业常用牌号**整理的材料参考库 —— 不是通用大宗行情。

- **37 个牌号**，六类：金属板材 / 塑料 / 橡胶 / 玻璃 / 有色金属 / 管材
- 含 22MnB5 热成型钢、HC340/590DP 双相钢、PP+EPDM-T20、PA66+GF30
- 含 EPDM / 天然橡胶 / 硅橡胶 / 丁腈橡胶，并标注「生胶 vs 混炼胶」密度差异
- 含 T2 紫铜、H62 黄铜、A00 铝锭、浮法玻璃原片、PVB 中间膜、尼龙管 PA11/PA12
- 每个牌号含密度、规格、典型应用、常见工艺；独立详情页
- 价格标注**数据来源与更新日期**，未收录的明确标「待补充」——**不编造价格**

### 🛠️ 常用工艺核算价格库 `craft/`

把常见工艺的**计价单位、计价基准、参考单价**集中在一处。

- **34 项**，五类：表面处理 / 冲压 / 铸造毛坯 / 线束 / 机加工
- **公开区（17 项）**：冲压各吨位冲次费、模具公斤价、喷漆 / 皮纹 / 电镀 / IMD
- **会员区（17 项）**：电泳、真空镀铝、软包覆、UV 硬化、压铸与铸件毛坯、线束物料、CNC 费率
- 每项标注**计价基准** —— 含哪几道工序、怎么算出来的

> **公开 / 会员的划分标准**：能从免费工具推导或已内置的一律公开
> （如冲压冲次费 = 机时费率 ÷ (SPM×60)），需要项目经验积累的才放会员区。
> **给客户能自己算出来的数据加锁，等于告诉他你在收智商税。**

## 📦 已上线的工具

### 🏭 注塑件成本模型 `injection/`

塑料件注塑成型成本估算，从材料费到含税报价全链路拆解。

- 双模式重量：精确净重输入 / 几何估算（研发阶段没有 3D 数模也能算）
- 模具费逐项构成：模架、型腔、滑块、斜顶、热流道、设计试模费
- 4 种物流模式：通用零担 / 供应商直送 / Milk-run / RDC
- 模具支付三模式：供应商全付 / 主机厂全付 / 按比例分摊
- **费率预设**：华东·高自动化 / 华东·通用（基准）/ 华南 / 华北 / 内陆·低成本，一键切换整套费率
- **材料价格批量导入**：粘贴价格表，3 分钟刷新整个材料库，自动记录来源与更新日期
- **账期资金占用**：填账期天数与资金成本，自动把垫资成本算进报价
- 管理费率、利润率、税率、废料价**全部可配置**（不再硬编码）
- 一键导出 Excel 成本报告（含计算明细与来源水印）

### ⚙️ 冲压件成本模型 `stamping/`

钣金件与冲焊总成成本估算，支持多层级 BOM 逐零件核算。

- 层级 BOM：总成 → 子件逐级展开，各件独立材料/厚度/工序
- **净重 / 下料毛重双口径**：材料按毛重计费，废料按真实差值回收
- 工序级冲次成本：按设备吨位自动匹配机时费率与 SPM
- 焊接关系编辑器：点焊 / MIG / 激光，按子件数量自动放大
- 工艺判例库：按尺寸与材料匹配相似件，一键套用工序配置
- **费率预设**、**板材价格批量导入**、**账期资金占用**（同注塑件）
- 历史快照：手动保存测算结果，用于方案对比

## 🎯 两条使用路径

| | 会调的人 | 不会调 / 懒得调的人 |
|---|---|---|
| **费率** | 直接改管理费率、利润率、模具单价 | 选一个「费率预设」档位 |
| **材料价** | 逐条编辑材料库 | 「批量导入价」粘贴价格表 |
| **结果** | 精确贴合本公司 | 10 分钟内得到可信的量级估算 |

> **设计前提：原材料价格是公开商品，不该由工具作者维护。**
> 所以「保持价格新鲜」被设计成客户 3 分钟能自己完成的操作——
> 工具作者不承担数据陈旧的责任，客户也不被锁定。

### 内容页是「生成」出来的，不是手写的

```
data/materials.json  ┐
content/*.md         ┴─▶ node tools/build-site.js ─▶ materials/ + kb/ + sitemap.xml
```

改数据或文章 → 重新构建 → 页面更新。**不要手工编辑 `materials/` 和 `kb/` 里的文件**，会被下次构建覆盖。

### 核心设计：一套引擎 × 三层覆盖

任何零件（注塑/冲压/压铸/机加工/线束…）的成本，都是同样 **7 个成本块**的组合。
品类差异只体现在「每个块用什么公式、填什么参数」：

| # | 成本块 | 公式 |
|---|---|---|
| 1 | 材料费 | 毛重 × 单价 − 废料回收 + 外购子件 |
| 2 | 加工费 | Σ(工时×费率) 或 Σ(冲次×单次费率) 或 循环时间×费率÷模穴数 |
| 3 | 工装摊销 | 模具总价 × 供应商分摊比 ÷ 生命周期产量 |
| 4 | 二次加工 | 处理面积 × 单价 × 工艺系数 ÷ 良率 |
| 5 | 连接装配 | Σ(焊点/螺栓/卡扣 数 × 单点费率) |
| 6 | 包装物流 | 包装摊销 + 运费/件 + 仓储 + EDI |
| 7 | 期间费用 | (1~6) × 管理费率 + 利润 + 税金 + 账期资金占用 |

**参数库（`cost-db.js`）才是护城河**，不是公式。因此参数库被设计为可按 Schema 维护、
带版本号与更新日期、可整包导出/导入、可从旧版 localStorage 自动迁移。

## 🚀 使用

**在线**：打开 https://gds-cb.github.io/cost-model/

**本地 / 内网**：直接双击 `index.html` 即可（无构建步骤、无依赖安装）。
如需在局域网共享：

```bash
npx serve .
# 或
python -m http.server 8080
```

> ⚠️ 请通过 HTTP 访问，不要用 `file://` 直接打开子页面 —— 浏览器会因同源策略拒绝加载
> 上级目录的 `assets/`。落地页本身可以直接双击打开。

### 数据备份（重要）

材料价格、设备费率、工艺判例保存在**本机浏览器**中。换电脑或清理浏览器数据前，
请使用工具内的「**导出备份**」下载 JSON；在新环境用「**导入备份**」恢复。
导入采用「同牌号合并」策略，不会删除本地已有的其他数据。

## 🧪 测试

```bash
npm test                  # 引擎 74 项 + 参数库 109 项 + 静态一致性检查
npm run test:engine       # 引擎单元测试
npm run test:db           # 参数库单元测试（价格解析 / 匹配 / 预设）
npm run check             # 静态一致性：id 引用 / CDN 残留 / 资源存在性
```

端到端 DOM 测试需要 jsdom（装在项目外，避免污染依赖）：

```bash
mkdir "%TEMP%\cost-domtest" && cd /d "%TEMP%\cost-domtest"
npm init -y && npm install jsdom
set NODE_PATH=%TEMP%\cost-domtest\node_modules
npm run test:dom          # 端到端：75 项
```

合计 **258 项断言**。关键回归项包括：

- 冲压件模具重量 = 6300kg（**不是** 8300kg，反证「模具×零件数量」的 bug 已修）
- 完全成本与独立手算一致（材料 + 加工 + 焊接 + 模具 + 物流，×1.232）
- 355T 需求映射到 400T 后结果与原 400T **完全一致**（反证设备匹配按「不小于」而非精确相等）
- 连续重算三次不产生历史记录
- 价格导入支持 8 种分隔符、大小写/全角/空格模糊匹配、表头与注释自动跳过
- 费率预设单调性（内陆 < 华北 < 华东通用 < 华东高自动化），且**不掺管理费率/利润率**

**改任何计算公式前，先让测试全绿。** 成本工具算错了比算不准更致命。
