整车成本控制是怎么做的：六个阶段一条链

2026-03-05 · #整车成本 · #目标成本 · #VAVE · #方法论

为什么需要一套流程

很多成本工程师的日常工作是这样的：拿到一张图纸或者一份报价，算一个数，报上去。

但那个数是从哪来的？为什么要控制在这个数？超出了怎么办？

这些问题的答案不在零件层面，在整车层面。整车成本控制不是"把每个零件算准"，而是一条从市场倒推到单个零件的链条。

链条是这六段：

#阶段一句话
1售价配置确认这车卖给谁、卖多少钱、有什么配置
2整车目标成本确认从售价倒推：整车最多能花多少钱
3分解零部件目标把整车目标拆到每个系统、每个零件
4初步方案成本预估这个设计方案，大概要花多少
5VAVE 方案成本达成差距怎么补：价值工程与价值分析
6零部件目标商务达成谈下来、定下来、写进合同

关键认知：这六段是接力，不是并列。

  • 第 1 段错了 → 后面全错（目标定高了浪费，定低了做不出来）
  • 第 3 段粗了 → 第 5 段永远补不上
  • 第 6 段松了 → 前面所有努力白费

下面逐段拆。

阶段一：售价配置确认

这是在定"天花板"。

一台车能花多少成本，不由工程师决定，由市场决定。

输入

  • 市场定位（A0 / A / B / C 级，什么人群）
  • 竞品价格带（同级别卖多少钱）
  • 配置表（有哪些功能、什么级别）

动作

  1. 确定配置清单：这车要有什么、什么档次
  • 有没有天窗？普通天窗还是全景？
  • 座椅是织物、仿皮还是真皮？
  • 有没有 L2 辅助驾驶？几个摄像头几个雷达？
  1. 确定建议零售价（MSRP）
  2. 预测销量（销量直接决定模具摊销、采购议价能力）

输出

售价 × 销量预测 + 配置表

⚠️ 这一段最常踩的坑

配置表后期变更。

配置表是所有成本工作的基准。如果配置在开发中途改了（加个功能、换个材质）， 整个成本链条都要重算——而现实中，配置变更几乎是必然发生的。

所以真正专业的做法是：在配置确认阶段就把配置变更的成本影响机制定下来。 每一条配置都要能回答"加这个功能，成本增加多少"。

配置表 ⇄ 成本表的双向映射

一个成熟的做法是维护一张配置-成本映射表：

配置项选项增量成本
天窗无 / 普通 / 全景0 / +X / +Y
座椅织物 / 仿皮 / 真皮0 / +X / +Y
辅助驾驶无 / L1 / L2 / L2+0 / +X / +Y / +Z

有了这张表，配置变更就是一次加法，而不是一次重算。

阶段二：整车目标成本确认

这是从"售价"倒推到"成本"。

输入

  • 售价（阶段一）
  • 销量预测（阶段一）
  • 竞品对标数据

动作

从售价往下一层层扣：

建议零售价（MSRP）
  − 经销商/渠道费用
  − 增值税、消费税等税费
  − 厂家目标利润
  ────────────────────────
  = 整车目标成本（出厂成本口径）

竞品对标怎么用

对标不是为了抄，是为了校准：

对标方式得到什么难度
拆解对标（Teardown）竞品每个零件的实物结构、材料、工艺高（要买车、要拆）
成本结构对标竞品各系统的成本占比中
参数对标同级别车的重量、尺寸、配置对应成本低

对标的核心结论往往是一句话：

"同级别、同配置的车，行业平均整车成本是 X，我们目标定在 X 的 95%，意味着要在哪几个系统上做到领先。"

输出

整车目标成本（以及初步的系统级分解）

⚠️ 这一段最常踩的坑

目标定得不切实际。

  • 定太松 → 供应商报价全都"达标"，公司白丢利润
  • 定太紧 → 项目后期疯狂砍配置，或者供应商亏本接单后偷工减料

判断标准：目标成本应该是"跳一跳够得着"。如果一个目标需要靠"供应商让利"才能达成， 那它就不是成本目标，是谈判目标——两者必须分开。

阶段三：分解零部件目标

这是整个链条里最考验功力的一段。

整车目标成本是一个总数，但真正要落地，必须拆到每一个零件。

分解的层级

整车
 └─ 系统（动力、底盘、车身、内外饰、电子电气…）
     └─ 总成（前门总成、仪表板总成…）
         └─ 零部件（门内板、骨架、饰条…）

四种分解方法（要混着用）

方法怎么做适用
历史结构法参照上一代车型的成本结构比例改款车型
竞品拆解法用拆解对标的成本数据反推全新车型
功能价值法按功能重要性分配成本（客户感知强的多给）差异化配置
自下而上法每个零件独立估算后再汇总校验关键零件

⚠️ 这一段最常踩的坑

只按比例分摊，不考虑零件实际差异。

最简单的做法是"上个车型这个零件占 3%，这个车型总成本降 5%，那它也降 5%"。这是最偷懒也最危险的做法。

因为零件的成本驱动因素完全不同：

  • 钢材涨价 → 钣金件成本上升，塑料件不受影响
  • 芯片涨价 → 电子件上升，结构件不受影响
  • 人工涨价 → 劳动密集件（线束、装配）上升，注塑件影响小

正确的做法：分解时要同时给出成本驱动因子，而不只是一个数字。

零件目标成本主要驱动因子敏感度
前门内板82 元钢材价格、模具摊销钢价 ±10% → 成本 ±4%
仪表板骨架45 元塑料价格、成型周期塑价 ±10% → 成本 ±6%
线束总成320 元铜价、人工铜价 ±10% → 成本 ±5%

有了驱动因子，第 5 阶段的 VAVE 才有抓手。

阶段四：初步方案成本预估

设计方案出来了，但它要花多少钱？

输入

  • 概念设计方案（CAS / 效果图 / 初步结构）
  • 阶段三给出的零件目标成本

动作

按设计方案做成本估算。这个阶段的输入是不完整的——没有详细图纸、没有工艺路线、甚至尺寸都还在变。

所以要用参数化估算：

精度档输入误差用在
L1 参数化只有尺寸/重量/品类±20~30%概念阶段
L2 简化路线品类 + 主要工序±10~15%设计定型
L3 完整参数全工艺/设备/模具/物流±5%报价/核价

这个阶段用 L1 就够了——它的目的不是算准，是尽早发现"这个方案根本达不到目标"。

输出

方案成本 vs 目标成本的差距（Gap）

Gap = 方案成本 − 目标成本

Gap > 0 → 需要 VAVE 补差距（进入阶段五）
Gap ≤ 0 → 可以直接进入商务阶段

⚠️ 这一段最常踩的坑

估得太粗，导致 Gap 被低估，后面收不住。

参数化估算最大的风险是系统性乐观——设计部门倾向认为自己的方案更简单、更容易做。

对策：估算时给出区间而不是单点值（最好/最可能/最差），并且对关键参数做敏感度分析： "如果成型周期从 60 秒变成 80 秒，成本会增加多少？"

阶段五：VAVE 方案成本达成

这是最容易被误解的一段。

VAVE = VA（价值分析）+ VE（价值工程）。核心不是"砍成本"，而是：

在保持或提升功能的前提下，降低成本。

差距怎么补

按优先级排序的手法：

优先级手法说明潜在降幅
1消除过剩功能客户感知不到的性能，砍掉大
2结构简化减少零件数、减少工序中~大
3材料替代高强钢替代普通钢减薄、工程塑料替代金属中
4工艺变更焊接改粘接、机加工改冲压中
5标准化/模块化多车型共用零件 → 摊销下降中
6供应商协同让供应商参与设计（ESI）小~中

⚠️ 这一段最常踩的坑

VAVE 变成了"砍配置"。

砍配置确实能降成本，但那是在降低产品价值，不是价值工程。

判断标准：

  • ✅ VAVE：功能不变，成本下降 → 利润增加
  • ❌ 砍配置：成本下降，但客户价值也下降 → 销量受损

如果一段降本方案需要市场部门点头同意"客户不会察觉"，那它就不是 VAVE。

一个必须建立的机制

VAVE 不是一次活动，是贯穿开发全过程的持续动作。所以要有：

  • 降本清单（谁提的、什么方案、省多少、什么时候落地）
  • 定期评审（每周/双周，跟踪落地率）
  • 达成率考核（不是"提了多少方案"，是"落地了多少"）

阶段六：零部件目标商务达成

前面所有的努力，都在这一段变成真金白银。

输入

  • 零件目标成本（阶段三）
  • 达成方案后的成本（阶段五）
  • 供应商报价

动作

  1. 询价与比价（多家供应商）
  2. 成本拆解核价（把报价按七块拆开逐项核对）
  3. 商务谈判（价格、账期、模具归属、年降条款）
  4. 定点与合同

核价时看什么

拿到报价，按七块成本结构对号入座：

检查点危险信号
有没有漏项报价里没提模具、没提包装 → 后期加钱
管理费率超过 15% → 偏高
利润率超过 15% → 偏高（但要结合行业）
模具摊销口径用年产量还是生命周期？口径不一致就没法比
材料利用率明显偏高 → 有水分
账期有没有算进价格里

⚠️ 这一段最常踩的坑

只谈价格，不谈总成本。

采购价只是 TCO（总拥有成本）的一部分。真正影响利润的还有：

  • 账期（90 天账期吃掉供应商 10%+ 的利润，最终会反映到报价）
  • 质量成本（不良率高的供应商，采购价再低也亏）
  • 切换成本（换供应商的验证、认证、模具费用）
  • 年降承诺（谈定 3 年 5% 的年降，比一次降价更值钱）

六段接力：一张总表

阶段输入核心动作输出精度要求主要责任方
1 售价配置市场定位、竞品定配置表 + 定售价售价 × 销量—市场 + 产品规划
2 整车目标售价、对标数据从售价倒推整车目标成本±5%成本 + 财务
3 零件分解整车目标、历史结构逐级分解 + 定驱动因子零件目标成本±10%成本
4 方案预估概念设计参数化估算Gap±20~30%成本 + 设计
5 VAVE 达成Gap价值工程降本清单 + 达成方案±10%成本 + 设计 + 供应商
6 商务达成达成方案核价 + 谈判 + 定点实际采购价±3%采购 + 成本

注意精度的演进：从 ±30% 一路收敛到 ±3%。

这就是为什么每一段都必须留有余量——你在阶段四用 ±30% 的估算去下结论， 到阶段六必然会被现实修正。留余量不是保守，是专业。

成本工程师在这条链上的角色

看完整条链会发现一件事：

真正难的从来不是"算一个零件的成本"。

真正难的是：

  1. 判断目标定得合不合理（阶段二）
  2. 把整车目标合理地拆到零件上（阶段三）
  3. 识别哪个参数最敏感（阶段四）
  4. 在功能不降的前提下找降本空间（阶段五）
  5. 把成本语言翻译成商务条款（阶段六）

这五件事，没有一件是"套公式"能解决的。它们需要的是——

对成本结构的理解 + 对工艺的认知 + 对商务的判断。

这也是为什么成本工程师不容易被工具替代：工具能算出数，但决定"这个数对不对、该不该接受"的，是人。
